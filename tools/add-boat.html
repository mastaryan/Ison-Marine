🚤 Ison Marine — Inventory Helper

This page never goes on the website. Open it from your computer, make your changes, download the updated data/boats.json, and deploy it like any other file.

Step 1 — Load your current inventory file

Pick the data/boats.json from the repo. Everything below edits that data.

Step 2 — Add a boat (or skip to Step 3 to update)

Upload the photos to images/boats/… first, then paste the path here.

No detail page yet? Leave it blank — the button will say "Contact Us" and link to the contact page.

Step 3 — Update or remove a boat

Marking a boat sold takes it off the for-sale pages. Add its photos to the sold gallery below if you want them shown there.

Step 4 — Sold gallery photos (optional)

Step 5 — Download the updated file

  1. Click Download boats.json.
  2. Replace data/boats.json in the repo with the downloaded file.
  3. If you added photos, make sure they're in images/boats/… too.
  4. Push to GitHub → pull in cPanel → copy to public_html/isonmarine — your normal deploy.
